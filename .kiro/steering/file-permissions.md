# 檔案操作紀律

## 修改前必須確認

1. **先分析、提方案、等人類確認** — 不可自行判斷就動手修改或刪除
2. **說明具體要改什麼** — 列出檔案路徑、改動內容摘要、改動原因
3. **人類明確說「可以」才執行**

## 禁止事項

- ❌ 未經確認就刪除任何檔案
- ❌ 未經確認就覆寫整個檔案（應使用局部替換，除非人類同意全文重寫）
- ❌ 一次改動多個檔案後才統一報告（應逐一確認）
- ❌ 改完不驗證就結案

## 版本控制意識

- 改動前確認是否需要備份原始內容
- 大量修改應分步驟進行，每步確認後才進下一步
- 不自行操作 git commit / push（除非人類明確要求）

## 驗證要求

- 每次寫入檔案後，重新讀取該檔案確認：
  1. 無亂碼（繁體中文完整呈現）
  2. 無截斷（內容完整）
  3. 邏輯與目的一致
- 逐檔驗證，不批量草率帶過

## 不走近路

- 一次只處理一件事
- 不確定的事情問人類，不自行假設
- 寧可多問一句，不要改錯再道歉
